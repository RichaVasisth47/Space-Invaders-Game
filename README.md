# Space Invaders (Python Turtle Game)

A classic arcade-style **Space Invaders** shoot 'em up game built using Python and the `turtle` graphics library as part of a Python programming journey.

## 🚀 Features

* **Colorful & Animated Design:** Brightly colored cyan spaceship, red enemy invaders, and yellow bullets with smooth manual screen updates.
* **Classic Controls:** Use the Left and Right arrow keys to navigate your spaceship and the Spacebar to fire bullets.
* **Dynamic Enemy Grid:** Enemies move across the screen and descend progressively, increasing the challenge.
* **Collision Detection:** Real-time distance-based collision tracking for bullets hitting enemies and enemies reaching the player.
* **Score & Game Over System:** Live score updates on the screen and a clean `GAME OVER` state handler that stops the game loop upon collision.

## 🛠️ Prerequisites

* Python 3.x installed on your system.
* No external dependencies required (uses built-in Python libraries: `turtle`, `math`, `random`).

## 🎮 How to Run

1. Clone or download this repository/folder to your local machine.
2. Open the project folder in your preferred IDE (such as PyCharm or VS Code).
3. Run the main game script:
   ```bash
   python main.py

Use the Left/Right Arrow Keys to move and Spacebar to shoot!
